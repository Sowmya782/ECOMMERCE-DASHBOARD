# E-COMMERCE SALES DASHBOARD (Interactive Dashboard using MS Excel)

---

## PROJECT OVERVIEW

- Analyze e-commerce sales and order performance.
- Understand customer purchasing behavior.
- Track product demand and popularity.
- Monitor delivery performance.
- Analyze customer ratings and satisfaction.
- Compare purchasing patterns across genders and order modes.

## KEY FINDINGS

- The dataset contains 2,400 orders.
- A total of 11,997 products/units were sold.
- Total sales amount is approximately $649.0K.
- The average customer rating is approximately 4.0.
- The average delivery time is approximately 2.3 days.
- Customer purchasing behavior can be analyzed through different order modes.
- Product popularity and customer preferences can be compared using the dashboard.
- Weekly trends help identify changes in e-commerce sales performance.
